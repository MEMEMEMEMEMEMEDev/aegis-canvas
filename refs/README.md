# Referencias visuales

Carpeta de trabajo para la dirección de arte de nuevas familias/marcas.
Suelta aquí lo que quieras mostrar: capturas, moodboards, fotos, PDFs,
fuentes (.ttf/.otf/.woff2), enlaces en un .md — cualquier cosa.

Uso típico en sesión:

1. Copias archivos aquí (vale crear subcarpetas, p. ej. `refs/proto/`).
2. Le dices a Claude "mira refs/" y los lee/analiza visualmente.
3. Iteramos: de las referencias salen paleta, tipografía y lenguaje formal,
   que se convierten en tokens/tema/componentes de la familia.

⚠️ El contenido NO se commitea (está en .gitignore, salvo este README):
las referencias suelen ser material con copyright de terceros. Lo que sí
se commitea es lo derivado: tokens, temas, fuentes con licencia OFL/Apache
en `src/fonts/` y componentes.
